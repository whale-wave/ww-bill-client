# 记账退款、返现与补款

## 展示约定

- 列表保留一条原记账记录，突出显示调整后的实际支出，并在下方划线显示原始支出。
- 退款、返现和补款汇总为一枚说明标签，不在列表中拆成多条独立账单。
- 点击原记录进入详情后，显示“原始支出 → 实际支出”和完整的多条调整历史。
- 只有支出记录显示调整区；收入记录不提供此能力。

## 详情交互

有记录编辑权限的用户可以新增、修改和删除调整。编辑表单包含：

- 类型：退款、返现或补款；
- 金额：最多两位小数，前端会阻止结果小于零；
- 实际发生时间；
- 可选资产账户和备注。

个人默认账本支持资产账户。家庭详情中，记录所有者可管理调整，其他成员只能查看，并且看不到所有者的私有资产信息。自定义账本遵循账本的记录更新权限。

保存成功后会刷新个人或账本记录、统计图表、家庭数据和资产数据。再次编辑已有调整的原记录时，编辑器使用 `originalAmount`，避免把净支出覆盖为新的原始金额。调整区的请求与提交编排收口在 `src/features/record-adjustment/`，记录实体层只保留 API、类型和缓存管理。

## API 形状

`RecordEntry` 的列表响应可包含 `originalAmount` 和 `adjustmentSummary`；详情响应还包含 `adjustments`。调整的写接口封装在 `src/entities/record/api.ts`，React Query 写操作封装在 `src/entities/record/hooks.ts`。
