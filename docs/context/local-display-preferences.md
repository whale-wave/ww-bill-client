# 金额显示偏好本机保存

个人、家庭和自定义账本的金额显示偏好只保存在当前设备的 `localStorage`，按登录用户及账本范围隔离。自定义账本的每日金额汇总开关同样属于本机显示偏好。切换后，同一页面和其他消费页面立即读取新值，刷新应用后仍保留；不同设备互不同步。

已有服务端值仅在当前设备没有本机值时导入一次。导入后以本机值为准，不再向用户配置、家庭偏好或自定义账本偏好接口发送这些显示字段。服务端旧字段保留用于旧客户端兼容，管理端不再把旧字段作为当前用户设置展示。

清理应用本地数据会清除这些偏好；再次进入时若服务端仍有旧值，会重新导入一次。新用户默认显示金额，自定义账本默认显示每日汇总。
