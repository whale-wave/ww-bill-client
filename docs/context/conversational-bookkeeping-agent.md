# 对话型记账第一版

## 入口与页面

个人记账明细页顶部的对话图标进入 `/agent`。页面提供会话历史、新建会话、流式回复、记账卡片和统计图表；会话 ID 保存在 URL 查询参数中，刷新后可恢复当前会话。

## 记账流程

1. 用户输入自然语言后，客户端通过 SSE 接收文本和结构化卡片。
2. `RECORD_DRAFT` 卡片不会直接写入账本，用户可以确认、取消或进入原有记账编辑器调整。
3. 从卡片进入编辑器时，路由状态携带 `actionId`、`conversationId`、分类和草稿。
4. 编辑提交调用 Agent 确认接口，成功后刷新账目缓存并返回原会话。
5. `RECORD_RESULT` 卡片可以跳转到既有记录编辑页。

## 统计流程

`STATISTIC` 卡片按后端提供的 `metric`、`chartType` 和 `points` 渲染指标、折线图、柱状图或环形图。查看相关明细会复用 `/search-record` 的 URL 筛选参数。

## 状态约定

- 服务端会话和消息使用 React Query 管理。
- 正在发送的一轮消息只保存在页面局部状态，完成后失效消息和会话缓存。
- 卡片结构带 `kind` 与 `version`，新增卡片版本时必须保留旧消息的可渲染能力。
- 当前语言分析由服务端确定性规则完成，客户端不依赖具体模型供应商。
