# 资产全景

资产图表页新增 `type=overview` 标签，无 `type` 参数时默认打开全景；既有资产、负债、净资产标签及旧链接保持可用。

全景复用现有资产账户与分组查询，不增加后端接口。连接表达当前资产构成，不表示实际资金流向或借款用途。正常情况下展示“负债账户 + 净资产 → 总资产 → 账户分类 → 账户”。银行叶子分组优先使用其父级账户类型，父级不可用时使用现有叶子分组。

金额计算保留十进制字符串，仅在图表绘制和百分比展示时转成数值。负债超过资产时，差额显示为“净资产缺口”；图表总量为资产侧和负债侧的较大值。负余额按相反方向绘制，顶部汇总仍保留账户的原始有符号资产、负债与净资产金额。零余额不生成色带。

全景支持金额、比例、隐藏金额三种模式。比例统一以图表总量为基准；顶部汇总在比例模式仍显示金额。隐藏金额同时隐藏汇总、节点与提示中的数值。手机横向滑动查看完整图表，标签过长时省略，节点提示显示完整名称与金额。图表宽度跟随容器变化，高度按账户数增长，滚动不拦截页面触摸手势。

仅开发模式提供 `/#/preview/asset-overview` 本地演示页面，使用同一个展示组件，明确标注演示数据，不写入用户账户或查询缓存。包含正常资产、负债超过资产和零余额场景。正式资产页始终查询真实数据。

验证包括十进制精度、同名节点、分类映射、负余额、负净资产、仅负债、零余额、图表节点收支平衡、URL 标签恢复和原有视图切换。
