# 记账位置

## 范围

- 位置是记账记录上的可选快照，不是持续定位，也不会在后台采集。
- 新建与编辑共用同一个位置选择面板。只有用户点击“确认位置”后，位置选择才会进入待提交记录。
- 快照保存 WGS-84 纬度、经度、定位精度、采集时间，以及用户可选填的位置名称。
- 当前版本不依赖第三方地图或逆地理编码服务；默认展示坐标，位置名称由用户确认或补充。

## 入口与状态

- 记账表单备注下方显示带定位图标的小标签。未选择时显示“添加位置”，已选择时显示名称或坐标。
- 面板支持重新定位、修改位置名称、明确选择“不记录位置”。编辑旧记录时，未操作位置不会覆盖已有值；明确选择“不记录位置”会提交 `null`。
- 个人记录、账本记录、家庭记录详情页均展示已保存的位置。账本 CSV/XLSX 导出包含位置名称、纬度、经度、精度和定位时间。

## 权限恢复

- Web / iOS 主屏幕入口使用浏览器定位权限，要求安全上下文（生产 HTTPS）。拒绝后会保留重试入口，并提示用户到 Safari / 系统设置恢复网站定位权限。
- Android 安装包使用 Capacitor Geolocation。拒绝权限后可直接打开应用设置；系统定位服务关闭时可直接打开定位服务设置。用户返回记账页后可再次点击重试。
- 权限拒绝、超时、设备不可用都不会阻断记账，用户始终可以选择不记录位置。

## 验收清单

- iOS Safari 与“添加到主屏幕”入口：首次允许、首次拒绝、设置中恢复权限、定位服务关闭、离线/弱定位。
- Android APK：精确位置、仅大致位置、拒绝、拒绝后打开应用设置恢复、关闭定位服务后打开系统设置恢复。
- 新建记录、编辑新增位置、编辑更换位置、编辑移除位置、详情回显、CSV/XLSX 导出。
- 确认应用不在打开位置面板前请求权限，且定位失败不影响普通记账提交。
