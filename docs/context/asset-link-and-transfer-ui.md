# 资产关联与转账界面

## 普通记账关联

个人系统默认账本的记账金额页显示可选的资产账户入口。未配置默认资产时初始为“不关联账户”；选择账户后，保存普通记录会同时生成资产流水。编辑时保持选择不动不会发送 `linkedAssetId`，显式选择“不关联账户”会发送 `null`。

快捷记账同样进入个人系统默认账本的记账编辑器，可选择资产账户；草稿确认接口把所选账户写入正式记录并同步生成资产流水。智能记账确认、家庭上下文与自定义账本上下文不请求资产列表，也不显示关联入口。

资产详情中的关联流水可以返回对应普通记录。普通记录编辑解除关联后，服务端只作废该笔资产流水；同账户后续或其它来源的流水继续显示并参与余额统计。

## 默认资产账号

设置页允许用户从自己创建的资产账号中选择默认值，也可以清除并恢复为每次手动选择。偏好保存在 `user_app_config.defaultAssetId`，因此跟随账号跨设备同步。服务端更新偏好前校验资产归属；数据库外键在默认资产被删除时自动将偏好置空。

默认值在新建个人普通记录和快捷记账草稿确认时应用。编辑既有记录、从类别或标签设置返回的已恢复草稿、智能记账、家庭账本和自定义账本都不会被默认值覆盖。客户端还会确认默认账号仍在当前资产列表中，避免把失效 ID 写入记录。

部署服务端前必须运行受保护的 TypeORM schema migration `AddDefaultAssetPreference2026091400400`；其评审 SQL 为 `2026091400400_add_default_asset_preference.sql`。

## 资产转账

资产详情底部提供转账入口。表单选择另一个账户、金额和发生时间，并通过随机幂等键提交。转账只影响资产账户，不计入普通收入或支出。

转账的两侧流水共享一个转账操作。用户从任一侧发起撤销时，前端调用整笔撤销 mutation，并统一失效资产列表、详情、流水和统计缓存，保证两个账户都刷新到一致状态。若任一账户已经删除，界面只展示流水说明，不提供撤销。

长列表选择器和转账表单使用统一的 `AppBottomSheet` / `SheetHeader` 结构：标题区不滚动，内容区独立滚动；所有主要触控目标至少为 44px。
