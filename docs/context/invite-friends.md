# 邀请好友海报与分享链接

“我的”页的“邀请好友”入口进入 `/invite-friends`。这是产品邀请页，不是家庭账本或自定义账本的邀请码页。

## 分享目标

- 海报二维码与分享链接统一指向 `https://whalewave.top`，让接收者查看产品介绍并选择网页版或 Android 客户端。
- 海报可以展示当前用户昵称，但不包含用户 ID、账单数据、家庭邀请码或账本邀请码。
- 当前没有邀请奖励、推荐关系或归因接口；不得把本页面描述成返利或裂变邀请码能力。

## 图片导出

- 页面预览与离屏导出共用 `InvitePoster`，导出宽度固定为 375px。
- 导出继续复用月账图片的字体、图片和渲染帧就绪检查，以及 Android 相册保存、Web PNG 下载能力。
- Android 保存成功后可以通过原生图片分享继续发送到其他 App；链接分享优先使用系统分享，环境不支持时复制文案与官网地址。

## 吉祥物素材

`src/assets/brand/whale-mascot-invite-v1.png` 是邀请场景的透明底位图。它保留蓝白鲸鱼、粉色脸颊和金色皇冠等现有品牌锚点，并增加挥鳍和邀请信动作。后续替换素材时保持透明背景、清晰轮廓和相近占位比例，避免影响海报布局与截图导出。
