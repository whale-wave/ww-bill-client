# 分类管理子分类宫格调整

更新日期：2026-09-22。状态：实现与本地验证完成，实体设备待用户加载新版确认。

## 用户要求

参考友商：一级分类下方的每个子分类只显示图标与名称，不接受子分类卡片内常驻“隐藏/前移”的展示。

## 调整与决策

| Before | After | Why |
| --- | --- | --- |
| 三列带独立底色的大子卡片 | 常规五列、360px 以下四列紧凑宫格，单项仅圆形图标和名称 | 匹配参考页面的密度和层次 |
| 单独二级分类标题与数量行 | 一级图标/名称区域提供折叠箭头 | 减少一层冗余标题 |
| 子项常驻隐藏、前移 | 点击子项进入编辑，编辑弹层保留操作 | 列表保持简洁，同时保留管理能力 |
| 宽大的“添加二级分类” | 宫格末尾同尺寸加号与“添加” | 与子项对齐 |

折叠遵循应用动态效果开关；只读用户可折叠浏览，无新增或编辑操作。长名称自然换行，图标底框等宽高，保留至少 44px 点击宽度。编辑里移动或隐藏后关闭弹层，避免排序更新版本后继续使用旧编辑状态。
