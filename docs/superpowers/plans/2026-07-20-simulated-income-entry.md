# Simulated Income Entry Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在鲸浪账本中为 2026 年 1–7 月新增 13 条符合已批准人设的收入流水，并验证新增收入合计为 267,080 元。

**Architecture:** 全部业务数据通过现有移动端账本界面录入，不修改应用代码、接口或数据库。先读取收入分类和原有流水，再分为固定工资与其他收入两个批次录入，最后按月份抽查并计算新增数据合计。

**Tech Stack:** Codex 内置浏览器、鲸浪账本移动端记账界面

## Global Constraints

- 基础工资为税前每月 40,000 元，账本记录实际到账金额。
- 新增 13 条收入，1–7 月合计 267,080 元。
- 不记录出差报销、借款或账户互转。
- 不修改或删除账本中的原有收入和支出。
- 7 月只使用截至 2026 年 7 月 20 日的日期。

### Task 1: 确认收入录入结构和原有数据

- Produces: 可用收入分类列表，以及 1 月、6 月、7 月原有收入基线

- [ ] **Step 1: 打开记账面板并切换到收入**

  点击底部“记账”，再点击顶部“收入”。预期：页面显示收入分类、金额键盘、日期和“完成”。

  优先确认“工资”“奖金”“兼职”“理财”“卖出”等分类；若名称不同，记录语义最接近的分类。预期：工资和每种其他收入都有明确分类。

- [ ] **Step 3: 取消测试表单并记录原有收入基线**

  不提交测试记录。查看 1 月、6 月和 7 月现有列表，记录原有收入，后续验证时不得覆盖或删除。
