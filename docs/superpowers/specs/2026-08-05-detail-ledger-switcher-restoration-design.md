# `/detail` 账本切换标题还原设计

**状态：** 待用户复核  
**日期：** 2026-08-05  
**涉及仓库：** `ww-bill-client`

## 目标

只还原个人明细页 `/detail` 的原有头部布局，并在原布局的标题位置接入现有账本选择器。家庭账本、自定义账本及其他复用共享组件的页面保持现状。

## 页面布局

- 顶部继续使用项目浅蓝主题和现有明细页数据区。
- 页面标题恢复居中，内容使用项目配置中的应用名。
- 搜索和日历恢复到标题右上角，沿用现有路由和日期参数。
- 月份、收入、支出和金额显隐位置及行为不变。
- 下方快捷卡恢复原三项：账单、预算、资产管家。
- 记录列表和个人模式底部导航不变。

## 账本切换交互

- `/detail` 标题使用现有 `LedgerTitleSwitcher`。
- “分账本快捷入口”开启时，标题显示下拉箭头，点击后打开现有 `LedgerSwitcherPanel`。
- “分账本快捷入口”关闭时，标题保持静态文字，不显示箭头，也不能打开面板。
- 面板沿用现有数据、导航、加载、错误、键盘焦点和遮罩关闭逻辑。
- 面板继续展示默认账本、自定义账本、当前项勾选，以及“创建账本”“账本管理”操作。

## 工程边界

- 只修改 `/detail` 页面适配层 `src/pages/record/detail/Top.tsx` 及其针对性测试。
- 不修改共享 `RecordOverviewHeader` 的布局和接口。
- 不修改家庭账本、自定义账本或其他页面。
- 不新增 API、全局状态、路由、样式体系或账本切换组件。

## 验收

- `/detail` 标题居中，搜索与日历位于右上角。
- 快捷卡只有账单、预算、资产管家三项。
- 快捷开关开启时点击标题可打开选择器；关闭时标题为静态文字。
- 搜索、日历、月份选择、金额显隐和快捷入口路由保持可用。
- 家庭账本、自定义账本以及共享头部相关测试无回归。
