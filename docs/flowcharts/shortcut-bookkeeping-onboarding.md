# 快捷记账安装向导流程

## 状态

快捷记账当前只支持“截屏 → 快捷指令 OCR → 生成待确认草稿 → 打开网页确认页”这一条链路。语音记账、URL Scheme 拉起 App 和 App 内直接确认不属于当前能力。

设置页在客户端内使用本地视图状态：`intro`、`create-key`、`key-created`、`install-guide`、`overview`、`usage-guide`、`connections`。

首次加载连接密钥列表后：无密钥进入介绍；存在任意有效密钥直接进入已配置状态。`lastUsedAt` 只用于连接管理中的最近使用信息，不作为页面阻塞条件。

## 一次性密钥边界

创建接口返回的完整密钥只存于当前页面内存，并只在创建成功后的页面显示。复制成功后立即转入安装说明，不写入 URL、本地存储、日志或全局状态。离开创建成功页前必须确认密钥将无法再次显示。

## 安装跳转

用户点击“复制密钥并添加快捷指令”后，先完成剪贴板复制，再显示粘贴示意图和三步说明。说明页使用 5 秒截止时间倒计时，计时结束自动打开经过 `getConfiguredIosShortcutInstallUrl` 校验的 iCloud 快捷指令链接；“立即打开”与自动跳转共享一次性跳转锁。

复制失败、链接无效或安装地址缺失时不启动倒计时，也不进行外部跳转。

## 恢复

用户从快捷指令返回后不恢复完整密钥，只重新读取服务端连接列表。连接密钥可在连接管理中停用，停用最后一枚后回到介绍页并重新开始设置。

## 使用说明截图顺序

使用说明采用单页长滚动布局，按用户提供的文件编号展示，不打乱操作顺序：

1. `01-get-shortcut`：在 iCloud 页面点击“获取捷径”。
2. `02-share-shortcut`：在快捷指令详情页点击“设置快捷指令”。
3. `03-token-empty`：找到 token 输入框。
4. `04-token-filled`：粘贴连接密钥。
5. `05-add-shortcut`：点击“添加快捷指令”完成安装。
6. `06-settings`：打开 iPhone“设置”。
7. `07-settings-accessibility`：在设置列表中点击“辅助功能”。
8. `08-accessibility-touch`：进入“触控”设置。
9. `09-touch-backtap`：点击“轻点背面”。
10. `10-backtap`：选择“轻点两下”。
11. `11-select-shortcut`：选择并绑定“鲸浪记账 截屏自动记账”。

安装完成后，用户截取包含消费信息的画面并运行快捷指令；快捷指令通过 OCR 识别内容，随后打开网页确认页，核对后才正式保存。
