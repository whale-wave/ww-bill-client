# Konsta iOS 源码适配：工坊与正式系统

更新：2026-09-29。工作分支：`codex/feat/konsta-ui-migration`。本记录承接 2026-09-18“分析 Konsta 风格展示方案”对话及 `docs/design-system-studio.md` 的已验收候选；正式系统现在也纳入适配范围。

## 约束与验收

- 直接参考仓库旁的 Konsta 源码，把所需组件和动效迁入项目自有 `shared/ui`；不安装、不运行时引用 Konsta。保留 MIT 许可。
- 工坊继续提供同一套效果的可交互预览；正式页面使用共享实现，不能由工坊和业务页各自维护一套外观相近但行为不同的控件。
- 以 9 月 18 日确定的 iOS default 风格为起点：鲸浪主色、透明轻模糊导航、原有页面顶部业务功能、44px 触控区、适度按压比例、减弱 Searchbar 阴影。主 Tab 不统一套返回导航；导航滚动效果在真实有导航的页面检查。
- 逐页在本地系统中验收明细、图表、记账、发现、我的，并覆盖实际使用这些控件的表单、设置、弹层和列表。验证 375px 与 430px 布局、滚动归属、触摸拖动、键盘、减少动态效果与功能状态。
- 用户负责后续打标签与构建发布；本轮只处理功能和本地验收，不执行发布。

## 当前审计

- 9 月 18 日候选代码位于 `StudioIosAdapters.tsx`、`ios-tabbar-gesture.ts`、`studio-ios.scss`，文档和可交互工坊均已存在。
- 此分支此前装入 Konsta 3.1.4 并全局替换旧组件。当前未提交工作正在移除该运行时依赖；`package.json` 已移除 Konsta，`App.tsx` 和 `main.tsx` 已移除其 App 包装。
- 业务页面仍有约 70 个文件使用 `konsta-compat`；这里大部分是简化的旧 API 兼容控件，尚不能视为 9 月 18 日源码效果的正式迁入。
- 本地浏览器确认工坊候选可用，正式客户端已登录且能进入明细、固定支出表单。此前的 UI 错乱需要以真实页面继续逐项处理。
