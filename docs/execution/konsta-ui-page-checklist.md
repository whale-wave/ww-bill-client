# 改版逐页验收清单

日期：2026-10-01。检查版本：客户端 `9c7a8a10`；对比基线：`origin/dev` 在本轮检查时的 `60391ef0`。服务端另涉及 native 外观模板及月账单打卡统计。这里覆盖此次改版差异，不把合入 dev 的其他功能算作本次样式迁移。

本清单按当前 `src/app/router.tsx` 的注册项核对：117 个路由检查项，含 3 个开发环境入口、启动入口、旧地址重定向和 404。资产表单的一项同时覆盖新增与编辑，关注列表的一项同时覆盖关注与粉丝。所有项目初始为“待确认”，此前本地测试或浏览器巡检不代替你的验收。

## 如何逐项确认

- 地址使用 Hash 路由：在当前站点域名后接 `#/detail` 这样的地址。无需更换域名。
- `:id`、`:ledgerId`、`:householdId`、`:recordId`、`:memberId`、`:requestId`、`:batchId`、`:code` 是占位符，使用已有数据的实际值；不要把冒号占位符原样打开。通过对应列表/邀请入口进入最稳妥。
- `:month` 格式为 `YYYY-MM`，例如 `#/bill/2026-09`。`:type` 在预算页为 0（月）/1（年）/2（日），在关注页为 follow/fans。`/asset/add-form/:id?` 有 id 为编辑；新增还需要实际分组参数，例如 `#/asset/add-form?groupId=实际分组ID`，应从添加账户的分组选择入口进入。
- 分类统计详情、个人记录详情/编辑、找回密码后续步骤、更换邮箱后续步骤、快捷记账确认、导入预览、应用锁管理等可能依赖上页传入状态或有效数据，应沿清单所述入口进入。分类详情的缺参数回退需另外测试。
- 范围“直”：页面入口或它调用的页面内组件文件直接修改；“共”：页面入口未直接改，但共享组件/能力有改动；“全”：此次只有应用根容器/全局主题样式的复查范围；“转”：旧地址重定向。共用组件的导入并不表示该页面所有子状态都实际展示了该组件。
- 每页检查基本布局后，再打开该页的弹窗、底部弹层、日期选择、编辑状态；仅看首页不能覆盖组件替换。
- 用真实手机检查触摸；窄屏 375px 与大屏约 430px 都应覆盖。主题至少覆盖当前主题和 native；其余主题在 G10 中集中复查。
- 可以按编号回复“P01 通过”“F02 问题：自动续费开关回填错误”“H04 暂无法检查：没有邀请码”。只有得到你明确确认的项才改为通过；缺数据、未走到的状态记待确认/阻塞。

## 共用交互检查

- [ ] G01 主 Tab：明细→图表→发现→我的往返；长滑/快滑/轻斜滑/连续滑；首尾不循环；中间记账按钮仍能点击；滑动结束后正常点击。
- [ ] G02 底栏：点击与触摸拖动均能切换；选中高亮跟随；拖动不误触记账；纵向滚动不切 Tab；家庭/自定义账本与资产页面底栏也检查。
- [ ] G03 记录/资产/固定支出滑动操作：左右展开、短滑回弹、连续展开不同项目、纵向滚动不误展开；按钮宽度边界无白条；点击/取消正常。
- [ ] G04 弹窗/Sheet：打开、遮罩关闭、关闭按钮、顶部入口再次点击收起；长内容只在弹层内滚动；键盘无遮挡；关闭后底页仍可滚动/点击。
- [ ] G05 日期选择：默认日期、取消不改变、确认更新；月底31日切到短月份、2月与闰年；最小/最大边界；带时间精度的入口；确认当前 select 形式是否接受。
- [ ] G06 表单：初始值/异步回填、清除按钮、必填/格式校验、开关/勾选/单多选/步进边界、提交加载与禁用、回车不误提交；取消不保存。
- [ ] G07 图片预览：单图、多图、默认索引、左右切图、双指缩放、双击放大、放大后拖动、关闭重开回到初始状态；消息/记录/社区都覆盖。
- [ ] G08 反馈与确认框：成功/失败/加载提示、取消/确认回调、连续弹出、无权限提示与禁用入口。
- [ ] G09 布局与可访问性：窄/宽屏、底部安全区、输入法、老年模式、减少动态效果；页头返回、底栏不遮最后一行；无意外横向溢出。
- [ ] G10 主题：native/fresh/minimal/glass 切换、刷新回显；明细/图表/我的/弹层/记账按钮一致；金额隐藏与收入支出颜色可辨。
